# 🚀 CatalogAI - Intelligent Product Cataloging System

**CatalogAI** is an AI-powered automated cataloging solution built for e-commerce, logistics, and supply chain vendors. It transforms raw product images and basic inputs into structured, professional, and marketplace-ready product listings in seconds.

---

## 🌟 Key Features
- **AI-Powered Image Recognition:** Automatically detects product category, specs, and details from uploaded product images.
- **Instant Description & Tag Generation:** Creates SEO-friendly product titles, descriptions, and tags.
- **Smart Categorization:** Automatically assigns correct categories and attributes to prevent manual data entry errors.
- **Interactive Web Interface:** Clean dashboard for sellers to inspect, edit, and confirm generated catalog data.
- **Fast Backend Server:** Powered by Python backend with seamless Gemini API integration.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (`index.html`, `style.css`, `script.js`)
- **Backend:** Python (`server.py`)
- **AI Integration:** Google Gemini API (Multimodal Vision)
- **Deployment:** Render (`requirements.txt`, `runtime.txt`)

---

## 💡 Problem Solved
Product cataloging in logistics and e-commerce is highly manual, error-prone, and time-consuming. **CatalogAI reduces the cataloging time by over 80%**, allowing sellers and warehouse teams to list thousands of items efficiently.
